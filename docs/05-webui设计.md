# nipaserver WebUI 设计 v1

> 2026-07-26。视觉稿：`webui/design/mockup.html`（单文件静态稿，浏览器直接打开）。
> 色板采用 dataviz skill 的验证参考色板（已通过 CVD/对比度六项检查，`docs/research/` 不再重复验证记录）；正式实现换品牌色时必须重跑 `validate_palette.js`。

## 1. 定位与美学方向

**"媒体库是舞台，agent 是幕后可见的管理员。"** 两种界面人格合一：

- **前台（海报墙）**：内容至上——海报即界面，chrome 退后。深色底让封面色彩自己发光；
- **后台（控制台）**：一个"活的"系统——agent 事件流实时滚动、工具调用逐条展开，用户能**看见 AI 在干活**。这是与 Jellyfin 最大的体验差异点，也是产品叙事的核心。

美学关键词：深色优先、玻璃拟态克制使用（仅顶栏与浮层）、大圆角（12/16px）、海报悬停微抬升、事件流等宽字体点缀、**不用渐变彩虹**（数据可视化纪律：色彩跟随语义）。

## 2. 设计系统

### 2.1 色彩（深色为默认，取自验证色板）

| 角色 | 值 | 用途 |
|---|---|---|
| 页面底 | `#0d0d0d` | body |
| 表面 | `#1a1a19` | 卡片/面板 |
| 表面-2 | `#242422` | 嵌套面板、输入框 |
| 主文本 | `#ffffff` | 标题、数值 |
| 次文本 | `#c3c2b7` | 正文 |
| 弱文本 | `#898781` | 标签、时间戳 |
| 发丝线 | `rgba(255,255,255,0.10)` | 边框 |
| 强调（accent） | `#3987e5`（series-1 dark） | 链接、选中、进度、主按钮 |
| good | `#0ca30c` | confidence=high、下载完成（恒配图标+文字） |
| warning | `#fab219` | confidence=medium、待确认 |
| serious | `#ec835a` | confidence=low |
| critical | `#d03b3b` | 失败、删除 |

浅色模式：同色板 light 列，v1.x 提供切换；先深色发布。

### 2.2 排版

- 全站 system-ui sans；**事件流/日志/hash 用 `ui-monospace`**；
- 大数值（统计）用默认比例数字；表格列用 `tabular-nums`；
- 层级靠字重与颜色，不靠字号轰炸：页面标题 20/600，卡片标题 15/600，正文 13.5，标签 12/muted。

### 2.3 组件语言

- 卡片：`#1a1a19` + 发丝边 + 12px 圆角，无投影（深色下投影读不出，用边线分层）；
- 海报：2:3，8px 圆角，悬停 `translateY(-4px)` + 边线亮起 + 标题浮现；
- 徽章（badge）：置信度/状态 = 色点或图标 + 文字，**永不只用颜色**；
- 按钮：主=accent 实心，次=表面-2 + 发丝边，危险=critical 实心且需要二次确认；
- 进度条：meter 规范——填充色带语义，轨道是同 ramp 的暗步。

### 3.1 管家页（v2 新增，规格见 06-管家设计.md §6）

- 左：对话面板——消息流内嵌富卡片：工具调用行（mono，含耗时）、条目卡（海报+id+依据，可点）、**整理计划卡**（删除线旧路径 → 绿色新路径 + 执行/调整按钮 + "需要你的确认"说明）、建议 chips + 输入框；
- 右：管家报告侧栏（巡检产出：缺集/订阅动态/复核建议，各带行动按钮）+ 管家状态卡（模型/今日消耗/下次巡检）。

## 4. 页面规格

### 4.1 媒体库（海报墙）

- **Hero 横幅（v2 新增）**：页首在追作品的大幅 backdrop 展示（标签徽章 + 大标题 + 继续观看按钮 + 季进度）——库的"今日头条"；
- 顶部：分组标签行（继续观看 / 最新入库 / 全部 / **按季度浏览**；后接库筛选下拉）——一行、左对齐（filters 规范）；
- **按季度浏览**：2026·冬/春/夏/秋 分组网格（air_date 驱动，见 06-管家设计 §2.1），追番场景一等公民；
- 继续观看：横滚卡片，海报底部 2px accent 进度条；
- 海报网格：`repeat(auto-fill, minmax(150px, 1fr))`，仅海报+悬停浮层（标题/年份/集数徽章）；**识别中的条目**显示占位海报 + 微光扫描动画 + "识别中"徽章——把 agent 的工作暴露在前台；
- 待确认条目在前台**不显示**（避免错误元数据污染海报墙），只在控制台出现——这是置信度闸门的 UI 表达。

### 4.2 详情页

- 顶部 backdrop（暗化 60% + 底部渐隐入页面底色），左海报右元信息（标题/原名/年份/评分/外部 id 徽章：TMDB/Bangumi/弹弹play 可点跳转）；
- 集列表：横向缩略图卡 + 观看进度条；每集显示弹幕 id 关联状态（有 episodeId = 弹幕可用徽章，§4.6 策略的 UI 面）；
- "识别信息"折叠区：该条目的 scrape transcript 入口（"这个条目是怎么被认出来的"——可解释性即产品特色）。

### 4.3 Agent 控制台（灵魂页）

三栏（可折叠为两栏）：

1. **左：任务队列**——过滤标签（运行中/待确认/失败/完成）+ 任务行（文件名、tier 徽章 L1/L2、状态点、耗时）；顶部四枚统计瓦片：今日已识别 / 待确认 / 队列中 / 今日 token 消耗（带 12 点 sparkline）；
2. **中：事件流查看器**（选中任务）——**timeline 形态**：
   - `round_started` = 分隔节点"Round 2/16"；
   - `tool_call_begin/end` 配对渲染为一张**工具卡**：图标 + 工具名（mono）+ 参数摘要 + 耗时徽章 + 展开查看完整输出预览；运行中的卡带脉冲点；
   - `assistant_message` = 引用样式气泡（弱化，它只是模型的自言自语）；
   - `task_completed` = 绿色终态卡（结果 JSON 结构化展示 + 置信度徽章）；`task_failed` = critical 终态卡（reason + message）；
   - 实时任务：SSE 追加，自动滚底（用户上滚则暂停跟随）；历史任务：从 transcript 回放同一渲染器（同构，契约 §4 不变量）；
3. **右：待确认审批队列**——审批卡：证据摘要（文件名+关键证据行）| AI 结论（海报缩略+标题+S/E+置信度徽章+一句话依据）| 动作行：✓ 确认 / ✎ 改正（弹搜索器）/ ⏭ 跳过。确认后卡片滑出，条目进入海报墙。

### 4.4 下载

- **0.1 已实现**：BT 任务列表、总体与单任务进度、状态/上传量/入库清单标记、暂停/恢复、删除任务及可选删除文件；
- **0.1 已实现**：RSS 订阅创建/编辑/启停/删除/立即检查，字幕组优先级、分辨率和排除正则过滤，以及最近检查时间/错误展示；
- **0.1 已实现**：活动任务、总体进度、完成数、启用订阅四枚统计瓦片，桌面与中等宽度响应式布局；
- **后续**：下载速度/ETA、torrent 文件清单与单文件优先级（等待 librqbit 快照 API 扩展）。

### 4.5 设置

分区左导航：媒体库（路径管理/扫描策略/整理开关三态 link→copy 显示）、AI 模型（预设卡片选择 + 自定义 base_url/key/model 表单 + "测试连接"按钮 + 首扫成本预估器）、弹弹play（凭证状态/appId）、TMDB（token + 署名声明展示——条款要求）、关于（开源许可 + TMDB logo 署名）。

## 5. 数据可视化件（dataviz 纪律逐条对应）

| 部件 | 形态 | 规范要点 |
|---|---|---|
| token 消耗 | 统计瓦片 + 12 点 sparkline | 瓦片契约：label/value/delta/trend；sparkline 单系列无图例 |
| 扫描进度 | meter | 填充 accent，轨道同 ramp 暗步；旁配数字 x/y |
| 下载速度 | 双系列 sparkline（下行 series-1 / 上行 series-3） | 2px 线 + 端点 dot + 图例（≥2 系列必有） |
| 识别成功率 | 统计瓦片 delta | 上升=good 文字色 |
| 事件流 | 非图表（timeline 列表） | 状态色恒配图标+文字 |

一律深色表面 `#1a1a19` 上渲染；文本永不穿系列色。

## 6. 交互细节

- 全局 ⌘K 搜索（条目/文件/设置项）；
- SSE 断线：顶栏扫描胶囊变 warning "重连中…"（Retrying 事件同款语言）；重连后事件流按 seq 续传（Last-Event-ID）；
- 审批键盘流：J/K 换卡、Enter 确认、E 改正——批量审确是高频操作，为它优化；
- 空状态皆有插画位 + 引导动作（"添加第一个媒体库"）；
- 所有破坏性操作（删除库/任务）二次确认，对话框写明后果。

## 7. 技术建议（供框架选型后落地）

- 倾向 Svelte 5 + Vite（§14 开放问题，最终由团队定）；CSS 用原生 custom properties（设计 token 直映射，无需 Tailwind 也可）；
- 图表全部手写 SVG（sparkline/meter 规模不值引入库）；
- 构建产物 rust-embed 进 nipa-server；开发期 Vite 代理 `/api/v1`；
- SSE 消费与 transcript 回放共用同一事件渲染器模块（事件同构是契约保证的）。
